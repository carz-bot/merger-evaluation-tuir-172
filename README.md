# MERGER_EVALUATION

Dashboard HTML relativa a un caso di studio interamente teorico sull'art. 172, comma 7, TUIR.

## Privacy e natura sintetica

Il progetto non contiene denominazioni societarie, codici fiscali, partite IVA, nominativi, indirizzi o riferimenti a procedimenti reali.

Le parti sono indicate esclusivamente come **Societa A** e **Societa B**. Date, annualita, importi di bilancio, perdite fiscali, margini e indicatori sono stati inventati da zero e non riproducono la cronologia, i valori o le proporzioni di alcun caso reale.

## Contenuti

- limite patrimoniale;
- test di vitalita;
- situazione infrannuale pre-fusione;
- risultati post-fusione espressi come Anno N, N+1 e N+2;
- schema di memoria difensiva;
- conclusioni e avvertenze metodologiche.

## Avvertenza

Il repository ha finalita esclusivamente didattiche e informative. Non costituisce consulenza fiscale, legale o parere professionale.

## Pubblicazione su GitHub Pages

1. Caricare tutti i file del pacchetto nella root del repository.
2. Aprire **Settings > Pages**.
3. Scegliere **GitHub Actions**, usando il workflow incluso, oppure **Deploy from a branch > main > /(root)**.
